## Context
项目已更名为 loembyA，但 `app/build.gradle.kts` 的基础 applicationId 仍为 `app.cineisle.player`，debug 通过 `.debug` 后缀生成旧包名。目标是让正式版使用 `com.github.npcdw.loembya`、debug 使用 `com.github.npcdw.loembya.debug`。

## 修改方案
1. **`app/build.gradle.kts`**：修改基础 applicationId 为 `com.github.npcdw.loembya`，同步附近注释；保留现有 debug 的 `.debug` 和 preview 的 `.preview` 后缀，各渠道自动继承新包名。
2. **保持源码 namespace `app.marlboroadvance.mpvex` 不变**，不迁移 Kotlin 包路径、Room schema、内部存储标识或签名配置。Manifest 的 `${applicationId}.provider` 已能自动跟随新包名；`AppIconManager` 已使用 `context.packageName` 和真实 Activity 类名，无需修改逻辑，仅更新其当前包名说明。
3. **`README.md`、`.github/badges/package-cineisle.svg`**：同步当前包名说明与徽章，适当加宽徽章以容纳新包名。明确新旧包名是不同应用，不能覆盖升级或自动继承旧应用本机数据，PostgreSQL 连接等本机配置需要重新填写。保留原项目历史链接。
4. **`.zcode/AGENTS.md`**：追加本次安装包名变更记录，覆盖此前“保留旧 applicationId”的历史约定。不修改用户已有变更的 `todo.md`。
