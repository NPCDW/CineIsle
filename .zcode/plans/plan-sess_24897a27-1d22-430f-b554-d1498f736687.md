## Context
将安卓端收敛为只读 Emby 检索/播放客户端：服务器和媒体内容只读取，不在安卓进行新增、编辑、删除。实际删除对应业务代码、页面、接口、后台任务和专用依赖，不仅隐藏按钮。继续以 PostgreSQL 为服务器配置唯一来源。

刚才边界问题未收到选择，本方案采用明确默认：**保留检索、浏览、详情、播放、自动播放进度上报，以及 PostgreSQL/外观/播放器等本机设置；删除手动业务增删改、下载/离线/保存和导入导出。** 自动播放上报是唯一保留的内容状态更新，不允许手动标记或清进度；PostgreSQL 始终只读。

## 1. 服务器列表改为只读选择
- 两套服务器管理页改为服务器列表，保留查询、刷新、错误重试、手动选择已有服务器。
- 删除新增、编辑、删除服务器、添加用户、备用服务器、自动主备切换、共享第二地址的按钮、弹窗、ViewModel 方法、业务接口和测试中的旧写入用例。
- 删除 `EmbyFailoverController`、故障接管/自动恢复任务、第二地址存储/竞速及相关请求失败 hooks。选择服务器不会触发自动切换。
- 保留 PostgreSQL 来源隔离、本机纯身份映射和内存成功快照；不读取旧 SQLite 服务器配置。

## 2. 普通代理忽略，反代保留
- 移除 `hasUnsupportedProxy` 对 browse/play代理、`follow` 的检测和阻断；不加载普通代理凭据、不配置 HTTP/SOCKS 代理，也不修改桌面字段。
- 只读加载 `reverse_proxy_server(id,name,url)`，关联服务器 `reverse_proxy_id` 和当前 `line_id` 对应的 `emby_line`。
- 按 loemby 规则计算反代地址：规范化反代 URL 末尾 `/`，再前缀拼接原 Emby 地址；不是用反代主机替换原主机，也不编码整个原地址。
- 先确定原站 API 前缀再套反代，统一用于认证、API、图片、视频、字幕等 URL。原站返回的绝对 URL按需反代化，第三方 CDN 直链不误加前缀。
- 列表明确显示**当前线路名称、反代名称/地址或未使用反代**；无安卓端线路编辑或切换写回。配置引用缺失/不一致时给出准确提示，不静默改选其他线路。
- 将旧 `EmbyEndpointResolver.kt` 中必须保留的 URL工具拆成无网络探测的只读解析器，删除其备用线路/地址竞速部分。

## 3. PostgreSQL 和会话严格只读
- 删除 `PostgresEmbyStore`、`EmbyServerRepository`、`EmbyRepository` 中所有共享配置 INSERT/UPDATE/DELETE、排序修改、线路写入和凭据回写方法。
- 收窄 JDBC 执行器为只读查询，连接设为 read-only、只读事务结束回滚；不暴露业务写事务接口。
- 需要自动认证时，仅在来源、UUID、账号和身份隔离的**内存会话层**保存 token/userId，不写共享表，也不新增明文偏好。数据库刷新不能把有效内存 token替换成过期值；来源/凭据变化时失效。
- PostgreSQL 连接配置仍允许本机 Keystore 加密保存；当前选择和身份映射属于本机运行状态，不是共享配置维护。

## 4. 删除其他业务增删改
- 删除收藏增删、手动已看/未看/清进度、不喜欢维护、合集/播放列表创建与编辑、聚合库维护、人物合并、重命名、复制移动、删除文件、上传等入口和对应实现。
- 收藏、历史、桌面已创建的合集/播放列表可继续只读浏览和检索；不能在安卓维护。
- 删除批量选择后变更操作、详情/卡片/播放器中的维护按钮，清理对应参数、状态、资源和未使用组件。
- 删除下载、离线管理、保存图片/媒体、分享上传、导入导出及其后台任务、服务、通知与专用存储业务；不删除用户已下载的物理文件。
- 本机设置保留，但移除与上述已删功能有关的设置项和搜索索引。必要字幕读取/播放临时缓存不作为离线管理功能。

## 5. 删除本地和网络 Tab及功能链
- Classic/Cine 均只保留首页、只读收藏、只读历史；删除本地/网络 Tab及内容分发，旧 Tab 状态超范围时回首页。
- 真正删除本地目录/视频/文件树浏览、媒体扫描、多选文件操作，以及 Cine 本地页面。
- 删除 SMB/FTP/WebDAV/AList 连接与浏览、网络目录封面、上传/下载中心、toolbox、网络照片和网络流协议代理/Provider等整条业务链。
- 清理 MainActivity 的文件协议自动连接/代理生命周期、App 的扫描与网络维护、DI、Manifest、权限、设置和专用依赖（SMBJ、Commons Net、Sardine及相关规则等）。
- 先移除播放器对本地扫描、数据库文件列表、网络连接ID和远程字幕查找的依赖，再删除模块；保留 Emby URI队列、HTTP播放、上下集、预加载、必要字幕读取和共享图片缓存。
- NanoHTTPD等仍被 Emby ISO/播放使用的依赖按反向引用保留，不按“网络”名称盲删。
- 不破坏现有用户数据：删除运行时DAO/仓库和维护代码，历史升级用的被动实体/迁移兼容壳可保留，不为删功能触发整库重建或删除下载文件。
